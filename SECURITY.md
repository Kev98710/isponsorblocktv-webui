# Security policy

## Reporting a vulnerability

Please report security issues privately via **GitHub → Security → Report a vulnerability**
in this repository instead of opening a public issue.

Include the affected version or image tag, a description of the issue and the steps to reproduce it.

## Scope

This repository covers the web interface (`webui/`), the Dockerfile and the build workflow.
Issues in iSponsorBlockTV itself belong to the
[iSponsorBlockTV repository](https://github.com/dmunozv04/iSponsorBlockTV).

## Supported versions

Only the latest image (`latest`) receives fixes.
